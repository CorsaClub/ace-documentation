# Instructions for the AI

## Technical documentation — mandatory vector search

This repository exposes a local vector index (`rag/db`, generated by [`rag/scripts/index_docs.py`](./rag/scripts/index_docs.py)) queryable through the MCP server `ace-rag` and its `search_docs(query, top_k)` tool.

**Before answering any question about the project's technical documentation** (vehicle physics schemas, fields, units, ACE asset structure, source PDF/Markdown content, etc.), you **must** call the `search_docs` MCP tool to run a targeted vector search, then base your answer on the returned excerpts (with their scores, `asset`, `section`, and `source`) instead of general memory or guesswork.

**Always phrase the `search_docs` query in English**, even if the conversation is in another language — the documentation and its embedding model are English-only, so an English query retrieves much better matches. Translate the user's question yourself before calling the tool.

If the `search_docs` tool is unavailable or `rag/db` does not exist yet, say so explicitly and offer to run `make rag-index` (see [README.md](./README.md#local-rag--vector-search-mcp)).
